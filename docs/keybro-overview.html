keybro for macOS

Every text field on your Mac, with Claude Code and a memory.

keybro lives in the menu bar. Press a hotkey in any app to draft a reply that understands the conversation, or to fix what you typed in your own voice. In the background it builds a local memory of people, promises and context that your Claude Code sessions can use too.

⌘⇧K Generate

Say what you mean. keybro writes it.

Click into any message box and press the hotkey. A small bar opens at your cursor. Type the idea in any language, Claude Code reads the chat on screen plus what it remembers about the person, and streams a reply in your tone.

  • Works in WhatsApp, Slack, Gmail, iMessage, LinkedIn, X and the terminal
  • Screenshot of the current window only, taken on the hotkey
  • Uses memory: who Rahul is, your last chats, how you talk to him
  • Three variants (casual, safe, bold). Arrow keys to switch
  • ↵ inserts into the field, ⇥ keeps chatting, esc cancels

⌘⇧L Fix

Fix the English, keep your voice.

Type the rough version and press the hotkey. keybro fixes grammar and spelling in place, using your style file so it still sounds like you. No em dashes, no corporate phrasing.

  • Fixes the selection, or the whole field when nothing is selected
  • Undo pill and ⌘Z restore the original
  • Hold ⌥ for professional, ⇧ for shorter
  • Hinglish in, clean English out

Menu bar

Quietly remembers what you type.

When you pause typing for about two seconds, keybro saves the text through the Accessibility API. When the field clears after you hit send, it becomes a sent message with the app, the contact and the time. No keystroke logging, no background screen recording.

  • Contact name from the chat header (browser extension, Accessibility tree, or OCR)
  • Password fields and blocked apps are always skipped
  • One click to pause

  • Click a node to open the person or topic
  • Search across everything, filter by app or time
  • Timeline view for "what was I doing last March"

People

Every person, with context that stays current.

One profile per person across apps. Facts carry a date and a source. When something changes, the old fact is closed instead of deleted, so memory stays correct and you can still look back.

  • Same person across WhatsApp, Slack and Gmail, merged at night
  • Every fact links to the message it came from
  • Edit or delete any fact. The change applies everywhere

Open loops and digest

Never forget what you promised.

When you write "I'll send it tomorrow", keybro notes it as a promise. It reminds you before it's due and closes it on its own once you actually send the thing. Each evening you get a short digest of the day.

  • Promises detected from what you send
  • Closed automatically when fulfilled
  • Unreplied messages you meant to answer

Claude Code + MCP

Your coding sessions remember too.

keybro runs on your existing Claude Code login through claude -p. No API keys. The same memory is exposed as an MCP server, so any Claude Code or Cursor session can ask what you worked on, what was decided, or who said what.

  • One command to connect: claude mcp add keybro
  • Tools: search, get person, timeline, open loops, today's context
  • Scoped access: work memory only, last 7 days, and so on

Settings and privacy

Local by default. You stay in control.

Memory lives in one SQLite file on your Mac. Light work runs on an on-device model, heavy work runs on your Claude Code. You pick the hotkeys, the apps it ignores, and what agents can read.

  • Remap hotkeys, with warnings when they clash with Slack or VS Code
  • Blocklist for banking and password apps
  • Privacy view shows what was captured and when
